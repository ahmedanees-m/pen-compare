# §0 — Overview

## §0.1 Purpose and scope

PEN-COMPARE is the capstone integrative paper of PEN-STACK. It answers a question that none of Papers 1–4 individually answers:

> *Given the four PEN-STACK datasets, how do we operationally certify an editor as a "Molecular Pen" rather than a "Molecular Scissor", with explicit literature grounding, threshold-sensitivity reporting, and a public interface accessible to non-computational biologists?*

The deliverable is a **framework** (5-gate hierarchical TrueWriterScore certification), an **analysis** (cross-source triangulation across all 4 PEN-STACK packages), a **public tool** (Streamlit webserver + local LLM RAG Q&A), and a **paper** (*Bioinformatics* Application Note).

Five user personas are served (see §0.4). The framework is not a novel ML method or a new biological discovery; it is a principled comparison and certification scheme for a rapidly emerging field that currently lacks one.

## §0.2 What PEN-COMPARE is NOT

| Out of scope | Reason |
|---|---|
| Novel ML method | Field doesn't need one here; methodological honesty matters more |
| New biology / wet-lab validation | Reserved for downstream wet-lab paper (separate effort) |
| Retraining mech-class or pen-score models | Models are locked at pre-registration; fixes go to v0.6.0 / v0.2.0 in future work |
| Adding new editors to upstream packages | Universe is frozen at pre-registration time; expansion is post-publication |
| Replacing PenScore | PEN-COMPARE *uses* PenScore as one of 8 axis inputs; it does not replace it |
| Paid API services | Zero-budget design (see §0.9); local LLM + free tiers only |

## §0.3 The "Writers, not Scissors" identity in PEN-COMPARE

The PEN-STACK manifesto (§1.4.3) defines a Molecular Pen by four biophysical properties: DSB Avoidance, Energy Independence, Target Specificity (programmable), and Therapeutic Deliverability. PEN-COMPARE operationalizes this via a **hierarchical 5-gate framework**:

**Necessary gate (must pass for any writer classification):**
- **G1 — DSB Avoidance** (S_DSB ≥ 0.95). Failing G1 → categorical NOT_WRITER, regardless of other gates. This architecturally enforces the pen-vs-scissors distinction. SpCas9 fails G1 by definition (S_DSB = 0.0) and cannot rescue itself by passing programmability, cargo, or any combination.

**Qualifying gates (count toward tier within the writer category):**
- **G2 — Programmability** (S_Prog ≥ 0.95) — sequence-programmable targeting
- **G3 — Native Cargo Capability** (S_Cargo ≥ 0.90 AND intrinsic cargo mechanism = True) — cargo delivered as part of the editor's catalytic mechanism, not via exogenous HDR template
- **G4 — Deliverability** (length ≤ 900 aa OR split-AAV eligible) — AAV-compatible
- **G5 — Evidence** (≥ 2 of {biochemical, structural, computational, cell_based}) — multi-source mechanism corroboration

**Tier requirements:**

| Tier | Necessary gate | Qualifying gates | Cell-based evidence | Example |
|---|---|---|---|---|
| TRUE_WRITER | G1 passes | All 4 pass | **Required** | ISCro4 |
| PROBABLE_WRITER | G1 passes | All 4 pass *but no cell-based* — OR — 3/4 with cell-based | — | IS621 (no cell data), Bxb1 (fails G2), evoCAST |
| EMERGING_WRITER | G1 passes | 1–2 pass | — | Many engineered designs |
| NOT_WRITER | **G1 FAILS** *or* 0 qualifying pass | — | — | SpCas9, AsCas12a |

**Why no S_Energy gate?** v3 dropped the original Gate 6 (Walker A/B regex). The motif-based test was biochemically trivial and excluded CAST family on superficial grounds. Under v3.2, CAST family (evoCAST, CAST_VK, CAST_IF) honestly lands in PROBABLE_WRITER (or TRUE_WRITER if cargo and cell-based pass) — multi-subunit ATP-dependent transposases are legitimate writer architectures, just architecturally distinct from single-protein bridge recombinases. S_Energy is retained as descriptive metadata in the editor profile output but not used in tier assignment.

## §0.4 Five primary use cases

The tool serves five user personas. Each maps to a webserver tab plus a Python API entry point:

| # | User persona | Use case | Webserver tab | API entry |
|---|---|---|---|---|
| 1 | **Bench biologist** considering an editor for a project | "Show me ISCro4 vs Bxb1 side-by-side" | Comparator | `Comparator.compare(editor_a, editor_b)` |
| 2 | **Field-survey reader** wanting all true writers | "List every editor in PEN-STACK certified TRUE_WRITER" | True Writers | `TrueWriter.list_certified()` |
| 3 | **Mechanism-curious reader** vetting a tool paper | "Is X really DSB-free? What evidence supports that?" | Triangulation | `Triangulator.audit(editor_id)` |
| 4 | **PEN-STACK newcomer** browsing in natural language | "What's the difference between MECH-CLASS and PEN-SCORE?" | Q&A | `RAG.ask(question)` |
| 5 | **Computational designer** filtering for targets | "Which Strategy D designs come closest to TRUE_WRITER on S_Immuno?" | Comparator + filters | `Comparator.filter_by_criteria(...)` |

All five workflows are exercised in the Application Note's "Worked Examples" section (Step 35).

## §0.5 Five pre-registered predictions

PEN-COMPARE pre-registers 5 predictions before any analysis. The hashes of `gates_v3.yaml`, `triangulation_rules_v3.yaml`, and `predictions_v3.yaml` are SHA-256 locked and git-tagged as `prereg-v3.2` before any analysis script runs.

| ID | Pre-registered prediction | Threshold | How tested |
|---|---|---|---|
| **P1** | Among natural (non-engineered) editors in the unified universe, **exactly 1 will be classified TRUE_WRITER** (ISCro4). No other natural editor will reach TRUE_WRITER under default thresholds. | n_natural_TRUE == 1 (and editor == "ISCro4") | Apply 5-gate framework; count natural editors with tier == TRUE_WRITER |
| **P2** | **Zero pen-assemble designs** will achieve TRUE_WRITER tier. Designs that beat IS621's PenScore lockpoint will cap at PROBABLE_WRITER due to missing cell_based_evidence (computational designs lack human-cell validation). | n_design_TRUE == 0 | Apply framework to v0.5.2 catalog; count designs with tier == TRUE_WRITER |
| **P3** | Triangulation flags **≥ 5 mechanism discrepancies** in the unified universe (cases where MECH-CLASS prediction disagrees with PFAM evidence, or pen-score axis disagrees with mech-class tier). | n ≥ 5 | Run triangulation on full universe; count `DISCREPANCY` records |
| **P4** | The local-LLM RAG (Ollama Llama 3.1 8B Instruct) correctly answers **≥ 80% of a 50-question PEN-STACK benchmark**. | accuracy ≥ 0.80 | Curated 50-question benchmark with gold answers from Papers 1–4 |
| **P5** | The Streamlit webserver loads and returns a comparison for any 2 of the top-10 PEN-SCORE editors in **≤ 3 seconds (p95)** on free-tier Streamlit Community Cloud. | p95 latency ≤ 3 s | Automated load-test on deployed app |

**Publication policy ladder:**
- 5/5 PASS → strong claim; *NAR Webserver Issue* stretch submission
- 4/5 PASS → honest report; *Bioinformatics* Application Note
- 3/5 PASS → reframe contributions; *Bioinformatics* Application Note
- ≤ 2/5 PASS → halt and rework

**Note on revisions from original v1.0 plan:** P1 and P2 were revised to match the v3.2 hierarchical-gate architecture. The original's P1 ("≥ 50 TRUE_WRITERs") and P2 ("≥ 1 Strategy D design is TRUE_WRITER") are architecturally incompatible with v3.2's cell_based_evidence requirement. The revised P1 and P2 are *more* falsifiable: P1 predicts uniqueness of ISCro4 (could fail if evoCAST also passes all gates including the new G3 native cargo test); P2 predicts the framework's strictness (could fail if any design has misrecorded cell_based evidence). P3, P4, P5 are unchanged from v1.0.

## §0.7 Engineering principles

PEN-COMPARE inherits and extends the engineering discipline of Papers 1–4:

1. **Pre-registration first.** Lock everything (gates, predictions, methodology, upstream SHAs) on OSF + git tag before any analysis runs.
2. **Single source of truth.** No hardcoded metadata in PEN-COMPARE. All editor properties retrieved via pen-score v0.1.3's `get_editor_metadata()` API.
3. **Hierarchical gates.** G1 is *necessary*; failing it auto-classifies as NOT_WRITER. Other gates count within the writer category.
4. **Sensitivity over fabricated noise.** Bootstrap with arbitrary σ is dishonest. Instead, vary each gate threshold systematically and report robustness fraction per editor.
5. **Multi-source triangulation.** Discordances between PEN-STACK packages are *findings*, not errors.
6. **Local LLM, never in critical path.** Ollama-based RAG powers the Q&A tab; if the LLM is unavailable, that tab degrades gracefully and core functionality continues.
7. **Zero-budget operations.** No paid APIs. Local LLM + free hosted tiers + free Streamlit deployment + free Zenodo + free OSF + free Codecov.
8. **Test coverage ≥ 85%.** Higher than Paper 4 (40%) because PEN-COMPARE has no external-tool dependencies in the critical path.
9. **Webserver works offline (locally) AND online (cloud).** Same Docker container deploys both ways.
10. **Honest publication ladder.** If only 3 of 5 predictions pass, the paper is submitted as a 3/5 report — not retrofitted.

```dockerfile
# pen-stack/compare:0.1.0 — Integration container for PEN-COMPARE
# Bundles all 4 PEN-STACK packages (v3-compat versions) + Ollama for local LLM RAG
FROM python:3.11-slim

    "mech-class>=0.5.4,<0.6.0" \

    "biopython>=1.83" "europepmc>=0.4.0"

# === Install Ollama for local LLM serving ===
# Ollama is a single binary; no Python dependency
RUN curl -fsSL https://ollama.com/install.sh | sh

# === Pre-download default models so first run is fast ===
# Llama 3.1 8B Instruct (~4.7 GB) — primary RAG model
# Phi-3.5 Mini (3.8B) (~2.2 GB) — CPU fallback
# Note: these run on first container start via ENTRYPOINT; not at build time
# (model weights would bloat the image; lazy-pull is better)

# === Install PEN-COMPARE itself ===
# In dev: bind-mount the repo and `pip install -e .`
# In CI/CD: install from PyPI when v0.1.0 is published
WORKDIR /workspace
COPY . /workspace/pen-compare
RUN pip install -e /workspace/pen-compare

# === Healthcheck ===
HEALTHCHECK --interval=30s --timeout=10s --retries=3 \
    CMD curl -f http://localhost:11434/api/tags || exit 1

# === Entrypoint: start Ollama daemon + lazy-pull models + Streamlit ===
COPY docker/entrypoint.sh /usr/local/bin/entrypoint.sh
RUN chmod +x /usr/local/bin/entrypoint.sh

EXPOSE 8501 11434
ENTRYPOINT ["/usr/local/bin/entrypoint.sh"]
```

**File: `docker/entrypoint.sh`**

```bash
#!/bin/bash
set -e

# Start Ollama daemon in background
ollama serve &
OLLAMA_PID=$!
echo "Started Ollama daemon (PID $OLLAMA_PID)"

# Wait for Ollama to be ready
until curl -sf http://localhost:11434/api/tags > /dev/null; do
    echo "Waiting for Ollama..."
    sleep 1
done
echo "Ollama is ready"

# Lazy-pull models if not present
if ! ollama list | grep -q "llama3.1:8b-instruct-q4_K_M"; then
    echo "Pulling llama3.1:8b-instruct-q4_K_M (one-time, ~4.7 GB)..."
    ollama pull llama3.1:8b-instruct-q4_K_M
fi

if ! ollama list | grep -q "phi3.5:3.8b-mini-instruct-q4_K_M"; then
    echo "Pulling phi3.5:3.8b-mini-instruct-q4_K_M (one-time, ~2.2 GB)..."
    ollama pull phi3.5:3.8b-mini-instruct-q4_K_M
fi

# Start Streamlit (default; can be overridden with `docker run ... bash`)
if [ "$#" -eq 0 ]; then
    exec streamlit run /workspace/pen-compare/pen_compare/server/app.py \
        --server.port 8501 --server.address 0.0.0.0
else
    exec "$@"
fi
```

```python
"""Cross-package smoke test. Must pass before any PEN-COMPARE code runs.

This is the first gate of PEN-COMPARE — verifies that all 4 upstream PEN-STACK
packages are at v3-compat versions and report consistent ISCro4 facts.
"""
import sys
import warnings

PASS, FAIL = "✅ PASS", "❌ FAIL"
results = {}

print("=" * 70)
print("PEN-COMPARE STEP 3: CROSS-PACKAGE SMOKE TEST")
print("=" * 70)

# Gate 1: genome-atlas v0.7.2+ with ISCro4 canonical
try:
    import genome_atlas
    assert genome_atlas.__version__.startswith("0.7."), f"Got {genome_atlas.__version__}"
    systems = genome_atlas.load_systems()
    assert "ISCro4" in systems, "ISCro4 not in foundational systems"
    iscro4 = systems["ISCro4"]
    assert iscro4.uniprot == "D2TGM5"
    assert "PF01548" in iscro4.pfam and "PF02371" in iscro4.pfam
    results["G1_genome_atlas"] = PASS
    print(f"Gate 1 — genome-atlas v{genome_atlas.__version__} + ISCro4 canonical: {PASS}")
except Exception as e:
    results["G1_genome_atlas"] = FAIL
    print(f"Gate 1: {FAIL} ({e})")

# Gate 2: mech-class v0.5.4+ — ISCro4 Tier-A gate fires
try:
    import mech_class
    from mech_class.api import classify
    assert mech_class.__version__.startswith("0.5.4"), f"Got {mech_class.__version__}"
    result = classify(accession="D2TGM5", pfam_hits=["PF01548", "PF02371"], sequence=None)
    assert result.tier_a_gate_override is True
    assert result.mechanism_class == "DSB_FREE_TRANSEST_RECOMBINASE"
    assert result.confidence >= 0.90
    results["G2_mech_class"] = PASS
    print(f"Gate 2 — mech-class v{mech_class.__version__} + ISCro4 Tier-A gate: {PASS}")
except Exception as e:
    results["G2_mech_class"] = FAIL
    print(f"Gate 2: {FAIL} ({e})")

# Gate 3: pen-score v0.1.3+ — get_editor_metadata API exists
try:
    import pen_score
    from pen_score import get_editor_metadata, score
    assert pen_score.__version__.startswith("0.1.3"), f"Got {pen_score.__version__}"
    md = get_editor_metadata("ISCro4")
    assert md.intrinsic_cargo_mechanism is True
    assert md.cell_based_evidence is True
    assert md.canonical_name == "ISCro4"
    results["G3_pen_score_metadata"] = PASS
    print(f"Gate 3 — pen-score v{pen_score.__version__} get_editor_metadata API: {PASS}")
except Exception as e:
    results["G3_pen_score_metadata"] = FAIL
    print(f"Gate 3: {FAIL} ({e})")

# Gate 4: IS621 cell_based_evidence=False (THE v3.2 CALIBRATION KEYSTONE)
try:
    md_is621 = get_editor_metadata("IS621")
    assert md_is621.intrinsic_cargo_mechanism is True, "IS621 has native cargo"
    assert md_is621.cell_based_evidence is False, \
        "IS621 must be False — this is what distinguishes it from ISCro4 in TRUE_WRITER tier"
    results["G4_is621_calibration"] = PASS
    print(f"Gate 4 — IS621 cell_based_evidence=False (v3.2 keystone): {PASS}")
except Exception as e:
    results["G4_is621_calibration"] = FAIL
    print(f"Gate 4: {FAIL} ({e})")

# Gate 5: SpCas9 intrinsic_cargo=False (Gate 3 reformulation)
try:
    md_spcas9 = get_editor_metadata("SpCas9")
    assert md_spcas9.intrinsic_cargo_mechanism is False, \
        "SpCas9 uses HDR template, not native cargo"
    results["G5_spcas9_cargo"] = PASS
    print(f"Gate 5 — SpCas9 intrinsic_cargo_mechanism=False: {PASS}")
except Exception as e:
    results["G5_spcas9_cargo"] = FAIL
    print(f"Gate 5: {FAIL} ({e})")

# Gate 6: IS622 deprecated alias resolves to ISCro4 with warning
try:
    with warnings.catch_warnings(record=True) as w:
        warnings.simplefilter("always")
        md_alias = get_editor_metadata("IS622")
        assert md_alias.canonical_name == "ISCro4"
        assert any("deprecated" in str(warning.message).lower() for warning in w)
    results["G6_alias_resolution"] = PASS
    print(f"Gate 6 — IS622 deprecated alias → ISCro4: {PASS}")
except Exception as e:
    results["G6_alias_resolution"] = FAIL
    print(f"Gate 6: {FAIL} ({e})")

# Gate 7: pen-assemble v0.5.2 catalog has new fields
try:
    import pandas as pd
    import pen_assemble
    assert pen_assemble.__version__.startswith("0.5.2"), f"Got {pen_assemble.__version__}"
    catalog = pd.read_parquet("repos/pen-assemble/data/catalog_v0.5.2_current.parquet")
    assert len(catalog) == 1029
    assert "intrinsic_cargo_mechanism" in catalog.columns
    assert "cell_based_evidence" in catalog.columns
    assert (~catalog["cell_based_evidence"]).all(), "All designs must have cell_based_evidence=False"
    results["G7_pen_assemble_catalog"] = PASS
    print(f"Gate 7 — pen-assemble v{pen_assemble.__version__} + catalog v0.5.2: {PASS}")
except Exception as e:
    results["G7_pen_assemble_catalog"] = FAIL
    print(f"Gate 7: {FAIL} ({e})")

# Gate 8: ISCro4 PenScore is computable and meaningful
try:
    iscro4_score = score("ISCro4")
    assert iscro4_score.axes["S_DSB"] == 1.0, f"S_DSB={iscro4_score.axes['S_DSB']}"
    assert iscro4_score.axes["S_Energy"] == 1.0
    assert iscro4_score.penscore > 0.85
    results["G8_pen_score_iscro4"] = PASS
    print(f"Gate 8 — ISCro4 PenScore computable: {PASS} (penscore={iscro4_score.penscore:.4f})")
except Exception as e:
    results["G8_pen_score_iscro4"] = FAIL
    print(f"Gate 8: {FAIL} ({e})")

# Final verdict
print()
print("=" * 70)

n_fail = 8 - n_pass
print(f"RESULT: {n_pass}/8 gates PASS, {n_fail}/8 gates FAIL")
if n_fail == 0:
    print("✅ Cross-package smoke test PASSED — PART B (Pre-Registration) is cleared")
else:
    print("❌ Smoke test FAILED — fix gates before proceeding")
print("=" * 70)

sys.exit(0 if n_fail == 0 else 1)
```

## Step 5: Assemble the unified editor universe

### Status
⏳ PENDING

### Duration
1.5 days

### Objective
Build the canonical `unified_editor_universe.parquet` — the single source of truth that all downstream PEN-COMPARE analyses consume. Deduplicate by UniProt where applicable; reconcile field conflicts; produce one row per "evaluable entity" (natural editor or computational design).

### Inputs
- Step 4 complete (3 inventory Parquets)

### Methods

**File: `pen_compare/core/universe.py`**

```python
"""Unified Editor Universe assembly.

The universe contains one row per evaluable entity:
- Natural editor (deduplicated by UniProt across sources)
- Computational design (one row per pen-assemble design_id)

Field reconciliation: when sources disagree, the precedence is
pen-score > mech-class > genome-atlas (most specific to least specific).
"""
from pathlib import Path
import pandas as pd
import numpy as np
from pen_score import get_editor_metadata, score, load_editor_universe
import genome_atlas
import pen_assemble

CANONICAL_UNIVERSE_PATH = Path("data/unified_editor_universe.parquet")

UNIVERSE_COLUMNS = [
    # Identity
    "entity_id", "source", "canonical_name", "aliases",
    "uniprot", "organism", "length_aa",
    # Mechanism
    "mechanism_class", "tier_a_gate", "mech_class_confidence",
    # PEN-SCORE 8 axes
    "s_dsb", "s_prog", "s_cargo", "s_energy",
    "s_immuno", "s_deliv", "s_mature", "s_spec",
    "penscore",
    # PEN-COMPARE v3.2 metadata fields
    "intrinsic_cargo_mechanism",   # for Gate 3
    "cell_based_evidence",          # for TRUE_WRITER tier requirement
    # Evidence sources (list)
    "has_biochemical", "has_structural", "has_computational", "has_cell_based",
    # Provenance
    "atlas_system_present", "in_pen_score", "in_pen_assemble",
    "parent_editor", "strategy",   # for designs
    "primary_doi", "secondary_doi",
]

def assemble_unified_universe() -> pd.DataFrame:
    """Build the unified universe Parquet."""
    rows = []

    # ===== 1. Natural editors from pen-score editor_universe =====
    universe = load_editor_universe()
    atlas_systems = genome_atlas.load_systems()

    for editor in universe.editors:
        scored = score(editor.id, profile="default")
        metadata = get_editor_metadata(editor.id)
        atlas_present = editor.id in atlas_systems or any(
            getattr(s, "uniprot", None) == editor.uniprot for s in atlas_systems.values()
        )
        row = _build_natural_row(editor, scored, metadata, atlas_present)
        rows.append(row)

    # ===== 2. Computational designs from pen-assemble v0.5.2 =====
    catalog = pd.read_parquet("repos/pen-assemble/data/catalog_v0.5.2_current.parquet")
    for _, design in catalog.iterrows():
        row = _build_design_row(design)
        rows.append(row)

    df = pd.DataFrame(rows, columns=UNIVERSE_COLUMNS)
    return df

def _build_natural_row(editor, scored, metadata, atlas_present):
    return {
        "entity_id": editor.id,
        "source": "natural",
        "canonical_name": metadata.canonical_name,
        "aliases": metadata.aliases,
        "uniprot": editor.uniprot,
        "organism": getattr(editor, "organism", None),
        "length_aa": editor.length_aa,
        "mechanism_class": getattr(editor, "mechanism_class", None),
        "tier_a_gate": getattr(editor, "mech_class_tier_a", False),
        "mech_class_confidence": getattr(editor, "mech_class_confidence", None),
        "s_dsb": scored.axes.get("S_DSB"),
        "s_prog": scored.axes.get("S_Prog"),
        "s_cargo": scored.axes.get("S_Cargo"),
        "s_energy": scored.axes.get("S_Energy"),
        "s_immuno": scored.axes.get("S_Immuno"),
        "s_deliv": scored.axes.get("S_Deliv"),
        "s_mature": scored.axes.get("S_Mature"),
        "s_spec": scored.axes.get("S_Spec"),
        "penscore": scored.penscore,
        "intrinsic_cargo_mechanism": metadata.intrinsic_cargo_mechanism,
        "cell_based_evidence": metadata.cell_based_evidence,
        "has_biochemical": getattr(editor, "has_biochemical_data", False),
        "has_structural": getattr(editor, "has_structural_data", False),
        "has_computational": getattr(editor, "mech_class_tier_a", False),
        "has_cell_based": metadata.cell_based_evidence,
        "atlas_system_present": atlas_present,
        "in_pen_score": True,
        "in_pen_assemble": False,
        "parent_editor": None,
        "strategy": None,
        "primary_doi": getattr(editor, "primary_source_doi", None),
        "secondary_doi": getattr(editor, "secondary_source_doi", None),
    }

def _build_design_row(design):
    return {
        "entity_id": design["design_id"],
        "source": "design",
        "canonical_name": design["design_id"],
        "aliases": [],
        "uniprot": None,
        "organism": "synthetic",
        "length_aa": design["length_aa"],
        "mechanism_class": "INHERITED",
        "tier_a_gate": True,  # IS110-derived designs inherit
        "mech_class_confidence": None,
        "s_dsb": design.get("s_dsb_v012", 1.0),
        "s_prog": design.get("s_prog_v012"),
        "s_cargo": design.get("s_cargo_v012"),
```

```python
"""5 gate functions: 1 necessary + 4 qualifying.

All thresholds come from config/gates_v3.yaml (SHA-256 locked at pre-registration).
"""
from dataclasses import dataclass
from enum import Enum
from pathlib import Path
import yaml

CONFIG = yaml.safe_load(
    (Path(__file__).parent.parent.parent / "config" / "gates_v3.yaml").read_text()
)

class GateRole(Enum):
    NECESSARY = "necessary"
    QUALIFYING = "qualifying"

@dataclass(frozen=True)
class GateResult:
    gate_id: str
    name: str
    role: GateRole
    passes: bool
    observed_value: float | None
    threshold: float | None
    rationale: str

def gate_1_dsb(s_dsb: float, threshold: float | None = None) -> GateResult:
    """NECESSARY gate: DSB Avoidance. Failing → auto NOT_WRITER."""
    cfg = CONFIG["necessary_gates"]["gate_1_dsb"]
    t = threshold if threshold is not None else cfg["threshold"]
    passes = s_dsb >= t
    return GateResult(
        gate_id="gate_1_dsb", name=cfg["name"], role=GateRole.NECESSARY,
        passes=passes, observed_value=s_dsb, threshold=t,
        rationale=f"S_DSB={s_dsb:.3f} {'≥' if passes else '<'} {t} (NECESSARY)",
    )

def gate_2_programmability(s_prog: float, threshold: float | None = None) -> GateResult:
    cfg = CONFIG["qualifying_gates"]["gate_2_programmability"]
    t = threshold if threshold is not None else cfg["threshold"]
    passes = s_prog >= t
    return GateResult(
        gate_id="gate_2_programmability", name=cfg["name"], role=GateRole.QUALIFYING,
        passes=passes, observed_value=s_prog, threshold=t,
        rationale=f"S_Prog={s_prog:.3f} {'≥' if passes else '<'} {t}",
    )

def gate_3_native_cargo(s_cargo: float, intrinsic_cargo_mechanism: bool,
                        threshold: float | None = None) -> GateResult:
    """Reformulated: HDR-template-based cargo does NOT count."""
    cfg = CONFIG["qualifying_gates"]["gate_3_native_cargo"]
    t = threshold if threshold is not None else cfg["threshold"]
    passes = (s_cargo >= t) and intrinsic_cargo_mechanism
    return GateResult(
        gate_id="gate_3_native_cargo", name=cfg["name"], role=GateRole.QUALIFYING,
        passes=passes, observed_value=s_cargo, threshold=t,
        rationale=(
            f"S_Cargo={s_cargo:.3f}, intrinsic={intrinsic_cargo_mechanism}; "
            f"need both S_Cargo≥{t} AND intrinsic cargo mechanism"
        ),
    )

def gate_4_deliverability(length_aa: int, split_aav_eligible: bool = False,
                          size_max: int = 900) -> GateResult:
    cfg = CONFIG["qualifying_gates"]["gate_4_deliverability"]
    passes = (length_aa <= size_max) or split_aav_eligible
    return GateResult(
        gate_id="gate_4_deliverability", name=cfg["name"], role=GateRole.QUALIFYING,
        passes=passes, observed_value=float(length_aa), threshold=float(size_max),
        rationale=f"length={length_aa}aa, split_aav={split_aav_eligible}, size_max={size_max}",
    )

def gate_5_evidence(evidence_sources: list[str]) -> GateResult:
    cfg = CONFIG["qualifying_gates"]["gate_5_evidence"]
    eligible = set(cfg["eligible_sources"])
    provided = set(evidence_sources) & eligible
    passes = len(provided) >= 2
    return GateResult(
        gate_id="gate_5_evidence", name=cfg["name"], role=GateRole.QUALIFYING,
        passes=passes, observed_value=float(len(provided)), threshold=2.0,
        rationale=f"sources={sorted(provided)} (need ≥2)",
    )
```

**File: `pen_compare/core/certify.py`**

```python
"""Hierarchical tier classification using the 5 TrueWriterScore gates."""
from dataclasses import dataclass
from pen_compare.core.gates import (
    GateResult, GateRole,
    gate_1_dsb, gate_2_programmability, gate_3_native_cargo,
    gate_4_deliverability, gate_5_evidence,
)

@dataclass(frozen=True)
class TrueWriterResult:
    editor_id: str
    tier: str
    necessary_gates_passed: int
    qualifying_gates_passed: int
    has_cell_based_evidence: bool
    gate_results: tuple[GateResult, ...]
    auto_demoted: bool
    auto_demote_reason: str | None

def certify(
    editor_id: str,
    s_dsb: float, s_prog: float, s_cargo: float,
    length_aa: int,
    evidence_sources: list[str],
    intrinsic_cargo_mechanism: bool,
    split_aav_eligible: bool = False,
    # Optional threshold overrides (used by sensitivity analysis)
    g1_threshold: float | None = None,
    g2_threshold: float | None = None,
    g3_threshold: float | None = None,
    g4_size_max: int = 900,
) -> TrueWriterResult:
    """Apply 5-gate hierarchical certification.

    NECESSARY gate (G1) auto-fail → categorical NOT_WRITER.
    Then within writer category, tier depends on qualifying gates + cell_based.
    """
    gate_results = (
        gate_1_dsb(s_dsb, threshold=g1_threshold),
        gate_2_programmability(s_prog, threshold=g2_threshold),
        gate_3_native_cargo(s_cargo, intrinsic_cargo_mechanism, threshold=g3_threshold),
        gate_4_deliverability(length_aa, split_aav_eligible, size_max=g4_size_max),
        gate_5_evidence(evidence_sources),
    )

    necessary_passed = sum(1 for g in gate_results if g.role == GateRole.NECESSARY and g.passes)
    qualifying_passed = sum(1 for g in gate_results if g.role == GateRole.QUALIFYING and g.passes)
    has_cell_based = "cell_based" in evidence_sources

    # Necessary gate auto-fail
    if necessary_passed < 1:  # G1 is the only necessary gate
        failed = [g for g in gate_results if g.role == GateRole.NECESSARY and not g.passes]
        return TrueWriterResult(
            editor_id=editor_id, tier="NOT_WRITER",
            necessary_gates_passed=necessary_passed,
            qualifying_gates_passed=qualifying_passed,
            has_cell_based_evidence=has_cell_based,
            gate_results=gate_results,
            auto_demoted=True,
            auto_demote_reason=f"Necessary gate(s) failed: {[g.gate_id for g in failed]}.",
        )

    # All necessary passed — assign tier within writer category
    if qualifying_passed == 4 and has_cell_based:
        tier = "TRUE_WRITER"
    elif qualifying_passed == 4 and not has_cell_based:
        tier = "PROBABLE_WRITER"
    elif qualifying_passed == 3 and has_cell_based:
        tier = "PROBABLE_WRITER"
    elif qualifying_passed >= 1:
        tier = "EMERGING_WRITER"
    else:
        tier = "NOT_WRITER"

    return TrueWriterResult(
        editor_id=editor_id, tier=tier,
        necessary_gates_passed=necessary_passed,
        qualifying_gates_passed=qualifying_passed,
        has_cell_based_evidence=has_cell_based,
        gate_results=gate_results,
        auto_demoted=False,
        auto_demote_reason=None,
    )
```

```python
"""Sensitivity analysis — replaces fabricated-σ bootstrap."""
import itertools
import numpy as np
import pandas as pd
from collections import Counter
from joblib import Parallel, delayed
from pen_compare.core.certify import certify

SENSITIVITY_GRID = {
    "g1_threshold": np.round(np.arange(0.85, 1.00, 0.01), 2).tolist(),  # 15
    "g2_threshold": np.round(np.arange(0.85, 1.00, 0.01), 2).tolist(),  # 15
    "g3_threshold": np.round(np.arange(0.80, 0.96, 0.01), 2).tolist(),  # 16
    "g4_size_max": [600, 750, 900, 1050, 1200],                         # 5
}
# Total: 15 * 15 * 16 * 5 = 18,000 combinations per entity

def sensitivity_for_entity(entity_row: dict, grid: dict = SENSITIVITY_GRID) -> dict:
    combos = list(itertools.product(*grid.values()))
    keys = list(grid.keys())
    tiers = []
    for combo in combos:
        c = dict(zip(keys, combo))
        result = certify(
            editor_id=entity_row["entity_id"],
            s_dsb=entity_row["s_dsb"], s_prog=entity_row["s_prog"],
            s_cargo=entity_row["s_cargo"],
            length_aa=int(entity_row["length_aa"]),
            evidence_sources=entity_row["evidence_sources"],
            intrinsic_cargo_mechanism=bool(entity_row["intrinsic_cargo_mechanism"]),
            split_aav_eligible=(int(entity_row["length_aa"]) <= 1500),
            g1_threshold=c["g1_threshold"],
            g2_threshold=c["g2_threshold"],
            g3_threshold=c["g3_threshold"],
            g4_size_max=c["g4_size_max"],
        )
        tiers.append(result.tier)
    counts = Counter(tiers)
    modal, modal_n = counts.most_common(1)[0]
    return {
        "entity_id": entity_row["entity_id"],
        "modal_tier": modal,
        "robustness": modal_n / len(tiers),
        "tier_dist": dict(counts),
    }

def run_sensitivity_parallel(scorecard: pd.DataFrame, n_jobs: int = 24) -> pd.DataFrame:
    # Build entity rows with evidence list
    rows = scorecard.to_dict("records")
    results = Parallel(n_jobs=n_jobs, verbose=10)(
        delayed(sensitivity_for_entity)(r) for r in rows
    )
    return pd.DataFrame(results)
```

```python
"""Build the RAG index over PEN-STACK docs + literature."""
from pathlib import Path
from sentence_transformers import SentenceTransformer
import chromadb

# Sources to index
DOC_PATHS = [
    "repos/genome-atlas/docs/", "repos/genome-atlas/README.md",
    "repos/mech-class/docs/", "repos/mech-class/README.md",
    "repos/pen-score/docs/", "repos/pen-score/README.md",
    "repos/pen-assemble/docs/", "repos/pen-assemble/README.md",
    "docs/",
    # Literature: top 50 cited papers per editor (~150 papers)
]

model = SentenceTransformer("sentence-transformers/all-MiniLM-L6-v2")
client = chromadb.PersistentClient(path="data/rag_db/")
collection = client.create_collection("pen_stack_corpus")

def chunk_text(text, chunk_size=512, overlap=64):
    """Sliding-window chunks."""
    words = text.split()
    for i in range(0, len(words), chunk_size - overlap):
        yield " ".join(words[i:i + chunk_size])

# Index every doc
import glob
for src in DOC_PATHS:
    for f in glob.glob(f"{src}/**/*.md", recursive=True):
        text = Path(f).read_text(errors="ignore")
        for i, chunk in enumerate(chunk_text(text)):
            embedding = model.encode(chunk).tolist()
            collection.add(
                ids=[f"{f}::{i}"],
                embeddings=[embedding],
                metadatas=[{"source": f, "chunk_idx": i}],
                documents=[chunk],
            )

print(f"Indexed {collection.count()} chunks")
```

**File: `pen_compare/rag/qa.py`**

```python
"""RAG Q&A using local Ollama LLM."""
import ollama
from sentence_transformers import SentenceTransformer
import chromadb

class PenStackQA:
    def __init__(self, model_name: str = "llama3.1:8b-instruct-q4_K_M", k: int = 5):
        self.model = model_name
        self.embedder = SentenceTransformer("sentence-transformers/all-MiniLM-L6-v2")
        self.collection = chromadb.PersistentClient(path="data/rag_db/").get_collection("pen_stack_corpus")
        self.k = k

    def ask(self, question: str) -> dict:
        # 1. Retrieve relevant chunks
        q_emb = self.embedder.encode(question).tolist()
        results = self.collection.query(query_embeddings=[q_emb], n_results=self.k)
        context = "\n\n---\n\n".join(results["documents"][0])

        # 2. Build prompt
        prompt = f"""You are a helpful assistant for the PEN-STACK genome engineering project.
Use ONLY the provided context to answer. If the answer is not in the context, say "I don't know."

CONTEXT:
{context}

QUESTION: {question}

ANSWER (concise, accurate, cite source filenames where possible):"""

        # 3. Generate
        response = ollama.generate(model=self.model, prompt=prompt)
        return {
            "question": question,
            "answer": response["response"],
            "sources": [m["source"] for m in results["metadatas"][0]],
            "model": self.model,
        }
```

```python
        "expected_keywords": q["gold_answer_keywords"],
```
